# RailSync landing page

Persian RTL marketing website starter for railsync.ir, built with Next.js 14, React, TypeScript and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Before publishing

- Replace `hello@railsync.ir` in `app/page.tsx` with the real sales email or replace the CTA with your preferred contact channel.
- Add the real phone number / WhatsApp / sales contact details.
- Confirm the exact product automation boundaries and revise the FAQ wording if needed.
- Review pricing, license terms, privacy policy, terms of use, and Chrome Web Store / site permissions before publishing.
- Product screenshots are stored in `public/product/` and were taken from the user-provided ZIP.

The color theme toggle and FAQ accordion work client-side. The contact CTA is currently an email link, not a backend form.
